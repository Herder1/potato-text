现行实现（三档显式清单 + 默认拒绝）：

| 接口 / 能力 | 未登录 | operator（运营操作员） | super_admin（超级管理员） | 证据 |
| --- | --- | --- | --- | --- |
| `POST /api/admin/auth/login` | 允许 | — | — | `server.js` 登录分支 |
| `GET /api/admin/auth/me`、`POST /auth/logout`、`POST /auth/password`（自助档） | 401 | ✓ | ✓ | `SELF_SERVICE_ADMIN_PATHS` |
| `/api/admin/accounts*`（后台账号管理） | 401 | 403 | ✓ | `SUPER_ADMIN_ONLY_ADMIN_PATHS` |
| `/api/admin/ai-config*`（模型供应商与密钥配置） | 401 | 403 | ✓ | 同上 |
| `/api/admin/ai/*`（路由、提示词、连通性测试） | 401 | 403 | ✓ | 同上 |
| `/api/admin/billing*`（收费、商品与额度发放） | 401 | 403 | ✓ | 同上 |
| 运营白名单（overview、moderation、operation-logs、questions、question-catalog、question-families、question-family-sets、question-family-options、question-enrichment、knowledge-structure、knowledge-dossiers、knowledge-dossier-deltas、knowledge-classification、adjudication、textbooks、exams、packs、announcements、ai-tasks、user-restrictions、community） | 401 | ✓ | ✓ | `OPERATOR_ADMIN_PATHS` |

| `/api/admin/exams/*` 内部导入 | 允许（记为 `system`） | — | — | 内部服务头 + 本机来源 + 限定前缀，三者缺一不可（`isInternalServiceRequest`，已单测） |
| 用户接口 `/api/auth/*`、`/api/*` | 需用户会话；非 production 才允许显式 `test-user` 兜底 | — | — | `server.js` `resolveRequestIdentity` |

会话与凭据策略（同为现状实现）：会话 12 小时；15 分钟窗口内 8 次失败锁定；密码 ≥8 位且不得等于用户名；`mustChangePassword` 为**服务端强制**（只放行 me/logout/password）；停用 / 重置密码 / 本人改密 / 登出立即撤销该账号全部会话；首次建号可用环境变量，但环境变量不能免登录。

用户侧限制（同属本轮口径，已落地）：禁言 / 禁止投稿 / 公开功能限制 / 账号封禁四类，**必须设到期时间（1–365 天）**、到期自动失效、**仅超级管理员可提前解除**；封禁即时撤销全部会话并拒绝登录。
