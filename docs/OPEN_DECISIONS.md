### 1.26 DEC-109 的落地细节：本地数据保留期限与"临时 B / 终局混合"的分界（2026-10-03）

**你已经定稿的部分**（9 条口径，已写入 [产品手册 §9.2.2](<../题库开发手册/一、产品手册（Project Blueprint）.txt>) 与 [模块 01 §6](modules/01-identity-auth.md)）：服务端是学习数据唯一权威；本地按 userId/accountId 独立命名空间保存；退出/切换**不得立即清空**；服务端不可达时保留快照并标"待同步"、不得伪装成已同步；登录新账号只读自己的命名空间；同步成功后按保留期限清理旧缓存与已确认同步的数据；不把本地全量存档当永久方案；补弱网退出/切换账号/同步失败/重登恢复的测试；API 地址与生产配置修复前不得宣称"退出登录数据绝对可恢复"。

**三个我替你取的默认值，等你一句话确认或改数**：

| 参数 | 当前默认值 | 含义 | 备选 |
| --- | --- | --- | --- |
| `SCOPE_RETENTION_DAYS` | **30 天** | 超过这么多天没登录的账号 → 整条命名空间（含存档）从本机回收 | 更短（省空间）/ 更长（更稳） |
| `SYNCED_SNAPSHOT_RETENTION_DAYS` | **7 天** | 已确认同步过（`lastSyncedAt>0` 且待同步队列为空）的账号，存档 7 天后只留簿记、丢掉数据副本 | 0（同步成功即丢，最省空间）/ 更长 |
| `MAX_ACCOUNT_SCOPES` | **3 个** | 本机最多保留几个账号的存档，超出的按最久未用回收 | 更多（多账号共用设备场景） |

**边界（已实现并有用例守住）**：guest → 登录账号时——
- **学习与复习数据**（知识卡与卡集、题目收藏、学习与复习进度、考试结果与诊断报告）**直接由该账号接管**，依据是"登录才能保存进度"与既有行为"未登录期间练习 → 登录后带走"；
- **个人资产（题包 / 我的资产 / AI 会话）与笔记草稿**：**不静默归属，改为登录时一次性确认**（产品负责人 2026-10-03 选定"统一归属 + 登录时一次性确认"）——弹一次「本机有 N 项内容，要归入当前账号吗？[归入当前账号]/[留在本机]」：归入 → 并入当前账号并**立即上行**；留在本机 → 不归入，且**同一份内容不再重复打扰**。**这一条取代 DEC-106 的"历史本地内容不自动归属"**：隐私初衷由"不静默上传"承接，方式从"静默丢弃"改为"可见地询问一次"；
- 账号与账号之间**严格隔离**，一个账号的存档不会被另一个账号看到（`tests/logout-workspace.test.js`）。

**为什么不是"静默自动归属"**：同一台手机上 A 未登录时建的题包，会被 B 登录后静默传进 B 的账号与云端，且**不可逆**（云端已收）——一次性确认能挡住这个，成本也低。

**"待同步"的可见性**：本轮把三条链路（学习记录 / 个人资产 / 卡集）的待同步状态集中到 `apps/miniprogram/utils/sync-status.js`，失败或未送达即标 pending、**只有收到服务端成功响应才清**。个人资产的文案早已如实（设置页"N 条内容尚未同步"/"同步未完成，本机内容已保留"）；学习记录与卡集的 pending **目前只落簿记、还没在界面上露出来**——这是下一步，不算已完成。

**临时 B / 终局混合的分界**：等 `RELEASE_CHECKLIST` **B7**（生产 API 地址与合法域名）修好、真机验证过"同步失败 → 保留 → 重登恢复"之后，再把"有服务端真源"的那部分本机副本改为同步成功即回收（即终局形态）。在此之前**不得**把本地全量存档当成永久数据方案，**也不得**对外宣称退出登录后数据绝对可恢复。
