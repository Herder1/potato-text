## 1. 产品定位【已确认】

薯考是一款面向**广东普通专升本汉语言文学**考生的微信题库、练习记录与复习工具。围绕指定科目和教材组织题目，以可信答案、教材依据和人工审核为内容底座，帮助用户找到练习范围、记录学习进度，并逐步判断下一步该练什么（产品手册 §1.1）。

- 核心属性是"软件工具"，不是学历教育、培训班、学校、教师授课平台或考试结果保证服务（§1.1）。
- 一句话说明：**把知识点拆开练，把进度看得见**（§1.1）。
- 长期价值方向：不只记录错题，还要帮助用户找到下一步该练什么，并用后续题目验证是否真正掌握（§1.1）。
- 核心用户：按教材学习、建立知识框架、开始刷题或阶段复习，且需要确认范围、检验掌握、保存学习资产的学习者（§1.2）。
- 核心任务：确认学什么 → 用题目检验 → 知道下一步练什么 → 获得同类/变式/延迟复测证据 → 保存学习资产（§1.3）。

**非目标**【已确认，§1.4】：不以题量最多为目标；不用少量题宣称 AI 精准诊断或预测分数；不承诺保过/押题/提分/证书；不允许 AI 自动修改、覆盖或发布权威答案；不复制同一题成多份实体；首期不做私信/关注/好友；不做实时授课、学籍或培训证书。

## 2. 首发范围【已确认】

- 对外统一表述：**薯考 · 汉语言文学题库 · 广东专升本**；不建立按年份复制的考试项目，年份只作试卷/来源/考纲/活动的元数据（§2.1）。
- 五科九本教材：现代汉语（上/下）、古代汉语（第 1/2 册）、中国古代文学（上/中/下）、中国现代文学（三十年）、中国当代文学（史）（§2.2）。
- 产品组成：原生微信小程序 + Node.js API + 网页管理后台 + 本地文件存储与 PostgreSQL 兼容层 + 教材 PDF/OCR 正文材料（§2.3，状态：已实现）。
- 当前阶段：内部开发与样板验证，**不是生产稳定版**；《现代汉语》是知识树、题族、知识档案与 Agent 巡检的首个样板（§2.4）。
- 一级导航固定为"题库 / 知识库 / 复习 / 发现 / 我的"，默认进入"复习"（§6.1，DEC-003）。

## 3. 跨模块原则【已确认】

以下五条贯穿所有模块，任何模块文档或实现都不得违反；详细表述见产品手册 §3。

1. **工具属性优先**（§3.1）：使用"题库、练习、题目包、练习规划、知识卡、复习工具、进度分析、AI 辅助解析/评分"等表述；完成专项资质核验前不使用"系统课、培训班、授课、名师辅导、保过、押题命中、提分保证、证书"等。
2. **可信内容优先**（§3.2）：教材 PDF/可核验原始资料是最终证据；AI 不得编造原文、页码、来源或官方意见；AI 生成内容必须标明来源和不确定性；题目、答案、教材引用、题族和规则**只有经过人工确认后才能进入权威链路或智能推荐**。
3. **一个事实只保留一份权威数据**（§3.3）：综合题池是虚拟查询不复制题目；公共/精选/平台题库是收录或权限关系；一题属多题族仍是同一题目 ID；不得生成内容副本。
4. **AI 建议、人工裁决**（§3.4）：AI 可以识别、提取、生成候选、检索相似案例、提示风险，但**没有最终发布权**；教材目录、题目、答案、知识树、知识档案、题族、规则和公开内容的正式状态必须由人工确认。
5. **承认证据不足**（§3.5）：必须保留"无法确定、证据不足、待归组、待人工审核"等状态；不得为了完成流程强行选择知识点、创建题族、给出精确诊断或伪造进度。
