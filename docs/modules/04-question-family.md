# 04 题族、成员审核与用户目录投影

> 模块编号仅用于导航。规则引用**权威正文**（产品手册），不替代原文。
> 相关：C6（已自查为"实现未交付"，非口径冲突）、C2（DEC 索引维护缺口）——见 [`../OPEN_DECISIONS.md`](../OPEN_DECISIONS.md)。

## 1. 职责与用户结果

- 职责：维护题族六组定义事实、题族集、成员归属与逐成员贡献知识；把已确认主题族按唯一范围锚点投影到教材目录；给出已归组/待归组统计。
- 用户结果：用户端题库目录按"教材骨架 + 已确认主题族范围锚点"组织，题目只随唯一主题族投影、按题目 ID 去重；未确认内容不进入用户目录。

## 2. 当前有效规则及原决策编号

### 【已确认】（正文见产品手册）

| 规则 | 来源 |
| --- | --- |
| 题族六组定义事实：名称、判别焦点、覆盖知识、教材定位（唯一范围锚点 + 多个证据锚点）、考查动作、纳入/排除边界 | §4.10、DEC-020 |
| 纳入/排除边界是题族语义字段，但普通人工确认时**选填**；缺失只形成待补充风险，不阻断确认；候选新题族草稿仍须完整边界 | §4.10、DEC-021 |
| 普通人工确认至少 1 道成员题且必须且只能保留 1 道原型题；只有 1 道成员可确认并派生"单题待扩充/样本不足"（质量提示，不是新审核状态）；0 成员空题族不可确认 | §4.10、DEC-023 |
| 范围锚点变更随题族确认/保存**一次原子写入**，同步目录路径、层级、排序、证据锚点、定义、成员与最终审核状态；失败全部不写入；成功后推进全部成员归属修订号，使引用旧归类的巡检建议失效 | §4.10、DEC-022 |
| 题族定义审核与成员归属审核分离；成员新增/移除/移动/成员题变化只精确失效对应成员关系，不把整个已确认题族退回待审核 | §4.10、DEC-038 |
| 成员关系独立状态 `confirmed` / `pending_fit`；`pending_fit` 只在管理后台显示，不进入任何用户侧正式消费 | §4.11 |
| 一道题只能有一个主题族；关联题族分 `required`（作答必需）与 `reference`（普通关联） | §4.11、DEC-037/039 |
| 联合覆盖门禁：主题成员 + 全部 `required` 关联成员的贡献知识并集必须与题目最小充分知识集**精确等价**；遗漏或额外都阻断保存 | §4.11 |
| 普通关联不保存贡献知识，不参与知识覆盖、专项训练或盲测题族命中计分；不得借它补足门禁 | §4.11 |
| 题族集严格树：一个题族最多一个直属题族集、一个下级集最多一个上级集；间接归入不得在上级集重复直属迁入；移动原子替换；解散只解除组织关系、保留题族与题目 | §4.12、DEC-016/017 |
| 目录投影四项门槛：题目是当前教材有效题 + 题族定义 `confirmed` + 成员归属 `confirmed` 且唯一主题族 + 题族拥有当前教材内有效且已确认的范围锚点；由稳定题目 ID 集合投影到锚点并向全部祖先递归汇总、按题目 ID 去重 | §6.2 |
| 已归组/待归组互斥且共同覆盖全部有效题；"无题族关系"只是待归组子集；统计必须现场派生，不得另存可独立增删的活动名单；旧 `unresolvedByBook` 仅作序列化兼容，不参与读取/统计/写入 | §6.2、DEC-024 |
| 训练条件：未确认题族不得进入智能复习；已确认题族中只有归属关系已确认且题目仍有效的成员可进入用户目录、智能复习、专项训练和正式统计 | §4.10、§7.3 |
| 单题题族可进入教材目录投影、主题族归因、原题复习和延迟复测；同类训练需排除当前题后仍有可用原型/同类题，变式训练需仍有可用变式题；缺哪项只禁用哪项并说明，不得跨题族硬凑或复制题目 | §7.3、DEC-023 |
| 删除最后一个已确认有效成员或唯一原型归属失效时，题族定义可保持已确认，但派生"暂无可用成员/原型待处理"，暂停进入用户训练，直至至少一条成员归属重新确认 | §4.10 |
| 范围锚点只回答"这一族放在哪个教材范围"，不进入题目最小充分知识集、成员贡献或联合覆盖；父子/祖先关系不得替代兼容校验 | §4.10、DEC-039 |
| Agent 找不到合适题族时只能生成"候选新题族草稿"，人工确认创建并归入后才产生正式题族与成员关系 | §4.10、§5.3 |

### 【实现事实·已核实】

- **用户端"专项训练"当前未实现**：`apps/miniprogram/` 全目录检索"专项训练" 0 命中；`server.js` 无"专项"字样，也没有按题族取题的练习端点。目录投影（`question-family-catalog-projection.js`）已实现，但它只产出目录统计，不等于训练闭环。
- 产品手册 §4.10/§7.2 的"已确认题族可进入专项训练"是**准入条件**，§7.3 的【规划中】是**交付状态**；两者不矛盾，因此**无需产品裁决**（C6 已自查关闭）。当前对外表述必须写"规划中"。

## 3. 状态流转与数据归属

```text
题族定义：待审核 ──人工确认──> 已确认 ──定义事实变化──> 待审核（重校全部成员）
                              已确认 ──最后成员删除/唯一原型失效──> 仍已确认 + 派生"暂无可用成员"（暂停用户消费）

成员归属：新增/迁移/题目内容·答案·指纹·贡献知识变化 ──> pending_fit ──人工确认──> confirmed
                                                                （pending_fit 不进用户侧）

题族集：空集可建 → 加入题族/下级集（严格树、原子移动）→ 解散需先处理下级集
```

- **数据归属（唯一）**：
  - 题族六组事实、题族集、成员关系、成员贡献 → `question-family-store.js`；
  - 易混/前置/相似/跨章节/共同案例等**动态关系** → `question-family-relations.js`（只读计算，展示依据与置信状态，不反向改写定义事实）；
  - 目录投影与归组统计 → `question-family-catalog-projection.js`（只读派生，管理端左侧徽标与右侧"正式投影题数"必须同源同范围）。
- 题目实体只有一份：一题属多题族仍是同一题目 ID，题族集与关联题族详情都不复制题目。

## 4. 跨模块输入输出及失效规则

**输入**：题目正式字段/版本与 `confirmed` 知识指纹（模块 02/03）；教材知识树节点与知识档案证据（未迁移）；后台身份与操作人（模块 01）。

**输出**：目录投影 → 用户端题库/复习/统计（未迁移）；成员贡献与联合覆盖结论 → 模块 03 的盲测计分与归类裁决；已归组/待归组统计 → 管理端题库工作区（§8.2）。

**失效规则**

| 触发 | 应失效/应保留 |
| --- | --- |
| 题目内容、正式答案或 `confirmed` 知识指纹发生**实质**变化 | 只把该题在各题族的成员归属与贡献知识标为 `pending_fit`；题族定义保持 `confirmed` |
| 来源、标签、难度、排版变化 | **不触发**任何题族或成员失效 |
| 成员新增/移除/移动、主题族↔关联题族切换 | 只影响本次变化涉及的成员关系；不得整族退回 |
| 题族判别焦点、覆盖知识、范围/证据锚点、考查动作、纳入/排除边界等**定义事实**变化 | 整个题族退回待审核并重校全部成员 |
| 名称、说明、排序、题族集层级等展示/组织字段变化 | **不触发**整族失效 |
| 范围锚点变更 | 一次原子写入同步全部目录事实与成员修订号；失败全部不写入 |
| 最后成员删除 / 唯一原型失效 | 定义可保留已确认，派生"暂无可用成员"，暂停进入用户训练 |
| 题目合并（模块 02 协议） | 受影响题族退回待审核并推进成员修订号 |

## 5. 禁止事项

- 不得让 AI 直接创建正式题族；只能产候选草稿，人工确认后才建族（§3.4、§4.10）。
- 不得同题重复加入同一语义题族；历史重复题族只作兼容别名解析，不复制题目（DEC-016）。
- 不得用共同父节点、祖先关系、题族范围锚点或题族整体覆盖范围替代**逐成员贡献**与联合覆盖门禁（§4.10、§4.11、DEC-039）。
- 不得借普通关联（`reference`）补足覆盖门禁，或让它进入专项训练推送/盲测计分。
- 不得在题族确认动作中修改、补齐或新建题目知识指纹，也不得推进题目版本（§4.10）。
- 不得另存"待归组活动名单"；不得让旧 `unresolvedByBook` 参与读取、统计或业务写入（DEC-024）。
- 不得为了凑成员数复制题目、强行合并相近题族或放宽题族语义边界（§4.10）。
- 不得手改 `.runtime` 题族数据；不得绕开正式 Store/API。
