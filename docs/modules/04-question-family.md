# 04 题族、成员审核与用户目录投影

## 1. 职责与用户结果

- 职责：维护题族六组定义事实、题族集、成员归属与逐成员贡献知识；把已确认主题族按唯一范围锚点投影到教材目录；给出已归组/待归组统计。
- 用户结果：用户端题库目录按"教材骨架 + 已确认主题族范围锚点"组织，题目只随唯一主题族投影、按题目 ID 去重；未确认内容不进入用户目录。

## 3. 状态流转与数据归属

```text
题族定义：待审核 ──人工确认──> 已确认 ──定义事实变化──> 待审核（重校全部成员）
                              已确认 ──最后成员删除/唯一原型失效──> 仍已确认 + 派生"暂无可用成员"（暂停用户消费）

成员归属：新增/迁移/题目内容·答案·指纹·贡献知识变化 ──> pending_fit ──人工确认──> confirmed
                                                                （pending_fit 不进用户侧）

题族集：空集可建 → 加入题族/下级集（严格树、原子移动）→ 解散需先处理下级集
```

- **数据归属（唯一）**：
  - 题族六组事实、题族集、成员关系、成员贡献 → `question-family-store.js`；
  - 易混/前置/相似/跨章节/共同案例等**动态关系** → `question-family-relations.js`（只读计算，展示依据与置信状态，不反向改写定义事实）；
  - 目录投影与归组统计 → `question-family-catalog-projection.js`（只读派生，管理端左侧徽标与右侧"正式投影题数"必须同源同范围）。
- 题目实体只有一份：一题属多题族仍是同一题目 ID，题族集与关联题族详情都不复制题目。

## 4. 跨模块输入输出及失效规则

**输入**：题目正式字段/版本与 `confirmed` 知识指纹（模块 02/03）；教材知识树节点与知识档案证据（未迁移）；后台身份与操作人（模块 01）。

**输出**：目录投影 → 用户端题库/复习/统计（未迁移）；成员贡献与联合覆盖结论 → 模块 03 的盲测计分与归类裁决；已归组/待归组统计 → 管理端题库工作区（§8.2）。

**失效规则**

| 触发 | 应失效/应保留 |
| --- | --- |
| 题目内容、正式答案或 `confirmed` 知识指纹发生**实质**变化 | 只把该题在各题族的成员归属与贡献知识标为 `pending_fit`；题族定义保持 `confirmed` |
| 来源、标签、难度、排版变化 | **不触发**任何题族或成员失效 |
| 成员新增/移除/移动、主题族↔关联题族切换 | 只影响本次变化涉及的成员关系；不得整族退回 |
| 题族判别焦点、覆盖知识、范围/证据锚点、考查动作、纳入/排除边界等**定义事实**变化 | 整个题族退回待审核并重校全部成员 |
| 名称、说明、排序、题族集层级等展示/组织字段变化 | **不触发**整族失效 |
| 范围锚点变更 | 一次原子写入同步全部目录事实与成员修订号；失败全部不写入 |
| 最后成员删除 / 唯一原型失效 | 定义可保留已确认，派生"暂无可用成员"，暂停进入用户训练 |
| 题目合并（模块 02 协议） | 受影响题族退回待审核并推进成员修订号 |

## 5. 禁止事项

- 不得让 AI 直接创建正式题族；只能产候选草稿，人工确认后才建族（§3.4、§4.10）。
- 不得同题重复加入同一语义题族；历史重复题族只作兼容别名解析，不复制题目（DEC-016）。
- 不得用共同父节点、祖先关系、题族范围锚点或题族整体覆盖范围替代**逐成员贡献**与联合覆盖门禁（§4.10、§4.11、DEC-039）。
- 不得借普通关联（`reference`）补足覆盖门禁，或让它进入专项训练推送/盲测计分。
- 不得在题族确认动作中修改、补齐或新建题目知识指纹，也不得推进题目版本（§4.10）。
- 不得另存"待归组活动名单"；不得让旧 `unresolvedByBook` 参与读取、统计或业务写入（DEC-024）。
- 不得为了凑成员数复制题目、强行合并相近题族或放宽题族语义边界（§4.10）。
- 不得手改 `.runtime` 题族数据；不得绕开正式 Store/API。
